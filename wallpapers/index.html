How this works

  1. Every clip or gif above is just a preview, it shows what the wallpaper looks like on-device, it isn't the file you install.
  2. The .tendies file is the actual wallpaper package. Tap Download .tendies to save it.
  3. Tap Open in Bad Poster to send it straight into the app, or import the downloaded file manually from within Bad Poster.

Wallpapers API

A plain JSON source listing every pack above, with preview and .tendies download URLs. Use it to pull these wallpapers into your own app or website.

nxtcoreee3.online/wallpapers/api.json
curl https://nxtcoreee3.online/wallpapers/api.json

Returns a packs array, each with name, description, author, and one or more versions (a label, previewURL, downloadURL, and file size in bytes). New packs get added to this file as they go up, no versioning needed on your end, just re-fetch it.
